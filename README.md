# 死契｜第一章 惡夢開端

依照手寫劇情筆記製作的恐怖解謎遊戲，場景使用實拍照片。

**線上遊玩：https://bravesheng.github.io/death-pact/**

## 怎麼玩

本機執行：在這個資料夾執行下面指令，再打開 http://localhost:8931

```bash
python3 -m http.server 8931
```

- 滑鼠點擊：調查、前進
- 方向鍵：在照片場景之間移動
- 夢境裡：方向鍵 / WASD / 拖曳畫面 轉頭（手機會出現方向鍵）
- `H` 顯示可調查的地方，`M` 靜音
- 建議戴耳機，含驚嚇畫面與音效

## 流程（對應筆記）

1. 房價便宜，買下房子 → 黑底序章
2. 騎摩托車到新買的房子 → 橫向捲軸騎車關卡
3. 找到鑰匙，讓大捲門打開 → 信箱紙條 → 電錶箱上的鑰匙 → 拉開鐵捲門
4. 一樓都是雜物 → 用照片做的 12 個場景可以探索（還能撿到之後會出現在夢裡的玻璃彈珠）
5. 走樓梯上二樓，沒有任何東西 → 空房間
6. 到家具店買家具 → 阿成家具行，老闆送一台老電扇
7. 睡著做了好長的夢（3D）：
   - 窗外下大雨、老電扇在床尾「咯噠、咯噠」擺頭
   - 仰躺視角、鬼壓床，只能用方向鍵轉頭
   - 彈珠「啪噠」掉下來，卻在天花板上滾向正中央 → 重力是反的
   - 床頭水杯的水面朝著地板、牆上照片開始微笑
   - 天花板龜裂、泛黃、滲出暗褐色液體
   - 畫面變黑白 → 鬼臉跳出來
8. 醒來，已經 10:30

## 測試用捷徑

網址後面加 `#場景名稱` 可直接跳關，例如 `#exterior`、`#living`、`#store`、`#bed1`、`#dream`、`#wake`。

## 檔案

- `index.html`、`css/style.css`
- `js/engine.js` 場景、對話框、HUD；`js/scenes.js` 劇本與照片場景熱點
- `js/ride.js` 騎車、`js/exterior.js` 新家門口、`js/store.js` 家具行
- `js/dream.js` 3D 惡夢（three.js r149，放在 `vendor/`）、`js/ghost.js` 鬼臉
- `js/audio.js` 所有音效都是程式即時合成，不需要音檔
- `assets/` 從 `photos/` 縮小後的照片（臥室鏡子裡拍到的人已經模糊處理）
