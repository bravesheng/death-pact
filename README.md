# 死契｜第一章 惡夢開端

依照手寫劇情筆記製作的恐怖解謎遊戲，場景使用實拍照片。

**線上遊玩：https://bravesheng.github.io/death-pact/**

## 怎麼玩

本機執行：在這個資料夾執行下面指令，再打開 http://localhost:8931

```bash
python3 -m http.server 8931
```

### 平板（iPad / Android 平板）

- 建議橫放；在 Safari 按「分享 → 加入主畫面」可以像 App 一樣全螢幕開啟（Android Chrome 按開始遊戲會自動全螢幕）
- 點畫面上的東西調查，右上角「？提示」標出可調查的地方
- 照片場景：左右滑動畫面，或點兩側的箭頭換房間
- 騎車：手指按住畫面催油門
- 夢境：手指拖曳畫面轉頭，或按右下角的方向鍵
- 點右上角的物品圖示可以看名稱

### 電腦

- 滑鼠點擊：調查、前進
- 方向鍵：在照片場景之間移動
- 夢境裡：方向鍵 / WASD / 拖曳畫面 轉頭（手機會出現方向鍵）
- `H` 顯示可調查的地方，`M` 靜音
- 建議戴耳機，含驚嚇畫面與音效

## 流程（對應筆記）

1. 房價便宜，買下房子 → 黑底序章
2. 騎摩托車到新買的房子 → 橫向捲軸騎車關卡
3. 找到鑰匙，讓大捲門打開 → 信箱紙條 → 電錶箱上的鑰匙 → 拉開鐵捲門
4. 一樓只有雜物間（可以撿到玻璃彈珠）
5. 離開雜物間 → 一樓通往二樓的玄關 → 看向樓梯 → 走樓梯影片：按住「往前走」才會前進，放開就停
6. 二樓才是住的地方，前屋主的東西都還在；最裡面的房間沒有床 → 走回樓梯口下樓
7. 到家具店買家具 → 阿成家具行（衣櫃換成新拍的照片），老闆送一台老電扇
8. 晚上：倒水、開電扇、關掉床頭檯燈睡覺
   - **有買床頭櫃** → 水杯放櫃子上 → 3D 惡夢（鬼壓床、重力反轉、天花板龜裂、鬼臉）→ 10:30 醒來（陰天的早上）→ 第一章結局
   - **沒買床頭櫃** → 水杯只能放地上 → 半夜渴醒，伸手拿水時紫指甲的手搶先碰到杯子：「這……這杯……不是……留給我喝的嗎？」→ 喝了一口滿是鐵鏽與香灰味 → 月光下一群黑影低頭吸水、一起轉頭對你笑 → 水裡浮著蛆 → 4:44 驚醒 → 第一章隱藏結局，跳出小框後回到主頁面
9. 徽章：達成不同劇情會獲得徽章，主頁面的「榮譽」可以查看（共 6 個）

主頁面下方會顯示版本與發布時間，並自動檢查是不是最新版本；有新版本時會出現「點這裡更新」。

## 測試用捷徑

網址後面加 `#場景名稱` 可直接跳關，例如 `#exterior`、`#shelf`、`#stairsup`、`#store`、`#bed1`（加 `?dresser=1` 為有買床頭櫃）、`#dream`、`#thirst`、`#wake444`。
加上 `?touch=1` 可以在電腦上模擬平板介面。

## 檔案

- `index.html`、`css/style.css`
- `js/engine.js` 場景、對話框、HUD；`js/scenes.js` 劇本與照片場景熱點
- `js/ride.js` 騎車、`js/exterior.js` 新家門口、`js/store.js` 家具行
- `js/dream.js` 3D 惡夢（three.js r149，放在 `vendor/`）、`js/ghost.js` 鬼臉、`js/thirst.js` 隱藏結局
- `js/badges.js` 徽章與榮譽頁；`js/version.js`、`version.json` 版本與發布時間（發佈時兩個都要改）
- `js/audio.js` 所有音效都是程式即時合成，不需要音檔
- `assets/` 縮小後的照片與影片（鏡子、窗戶裡拍到的人已經模糊處理；影片已去掉原始聲音）
